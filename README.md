# 3-Phase Star-Delta Motor Starter Using Magnetic Contactors

> A practical Electrical and Electronic Engineering (EEE) project demonstrating the wiring and operation of a Star-Delta starter for a three-phase induction motor using magnetic contactors.

---

## Project Overview

This project demonstrates the practical wiring and operation of a **Star-Delta Motor Starter** for a **three-phase induction motor**.

A Star-Delta starter is a commonly used motor-starting method in which the motor is initially connected in **Star (Y) configuration** during starting and is then changed to **Delta (Δ) configuration** for normal operation.

The main purpose of the Star-Delta starting method is to reduce the motor's starting current compared with starting the motor directly in Delta.

This project was implemented as a practical electrical wiring project using **magnetic contactors** and a three-phase induction motor.

The repository contains:

- Practical Star-Delta circuit diagram
- Real project demonstration video
- Motor terminal configuration
- Magnetic contactor-based control
- Working principle
- Star and Delta connection concepts
- Practical safety considerations
- Learning outcomes

# Basic Principle

A three-phase induction motor can be started using different starting methods.

In the Star-Delta starting method, the motor is initially connected in **Star configuration**.

After the motor gains sufficient speed, the connection is changed to **Delta configuration** for normal operation.

The basic operating sequence is:

```text
Three-Phase Supply
        │
        ▼
Main Contactor
        │
        ▼
Star Connection
        │
        ▼
Motor Starts with Reduced Starting Current
        │
        ▼
Motor Accelerates
        │
        ▼
Star Connection Disconnected
        │
        ▼
Delta Connection
        │
        ▼
Normal Motor Operation
